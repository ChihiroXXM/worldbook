WorldBook Gallery · Handbook
使用说明

世界书收藏馆是一个放在浏览器里的小书架：收着你常用的世界书，随时搜、随时改、一键复制去酒馆。下面按用到的先后排好了，挑需要的看就行。随时按 ? 可以再打开这本说明。

01

开始之前

Before you start

所有数据都存在当前这个浏览器里，不会上传到任何地方。好处是打开就能用、不用注册；代价是清理浏览器缓存、换浏览器、换电脑，数据就看不到了。

所以第一件事：去 更多 → 备份与云同步，导出一份备份，或者设置好云同步。超过 7 天没备份，页面顶部也会提醒你。
02

把世界书放进来

Add & import
手动添加

右上角 + 添加，粘贴内容，填名称和作者。分类、关键词、来源、版本都可以不填。

导入文件

更多 → 导入文件，一次可以选好几个。支持 .txt、.md、.json 备份，还有 Word 的 .docx / .doc。

直接拖进来

把文件拖到页面任意位置，松手就开始导入。

如果导入的书和已有的同名同作者，会先弹出预览。内容一样的默认跳过，内容不同的可以选：

跳过保留本地的，不导入这本。
覆盖本地用导入的替换本地内容。替换前，本地内容会自动存进「历史版本」，改错了能找回来。
保留两份都留下，新导入的名字后面加「（新导入）」。
Word 里设置成「标题 1 / 标题 2」的段落，导入后会变成 # 和 ##，「分段」和「大纲」就能直接用了。老的 .doc 只能读出文字，如果有乱码，在 Word 里 另存为 .docx 再导入就好。
03

找到想要的那本

Search & filter

顶部搜索框会同时搜名称、作者、关键词、备注和正文。空格分开的几个词要同时满足。搜到的词会在列表里标出来，下面还会显示一行正文摘要，告诉你有几处匹配。点开那本书，会直接跳到第一处。

按功能分 / 按作者分

点左栏上方的两个标签，展开就能筛选。已经生效的筛选会显示成小胶囊，点一下就取消。

收藏

书页上的 ☆ 可以收藏，收藏的书永远排在最前面。列表上方的「收藏」可以只看收藏。

排序和密度

可以按名称、最近编辑、最近使用、字数排序。旁边的按钮可以切换成紧凑列表。

04

阅读与编辑

Read & edit

点开一本书，右边就是书页。直接在内容区打字就能改，自动保存，不用按保存。刷新页面后，会回到你上次看的那本书和位置。

分段

按 ## 标题、【条目】或 <标签> 自动切开，每段都能单独复制，还能看到估算的 tokens。

大纲

列出所有标题，点一下就跳过去，长世界书里很好用。

查找替换

只在这本书里找，支持区分大小写和正则。全部替换之后可以在历史版本里撤回。

历史版本

⋯ → 历史版本，自动留存最近 8 个版本，能看对比，一键恢复。

专注模式

书页右上角的 ⤢，把其他东西都藏起来，按 Esc 退出。

来源和版本

点「编辑」可以填来源链接、版本号、作品更新日期。别人的作品更新了，你能记得自己用的是哪一版。

整理书架

Organize

作者管理

07

删错了也不怕

Recycle bin & backup
回收站

删掉的书会在 更多 → 回收站 里保留 30 天，连同它的历史版本。30 天内随时可以还原。

历史版本

内容改坏了，到 ⋯ → 历史版本 里找回之前的版本。导入覆盖、云端拉取之前，也会自动存一份。

导出备份

更多 → 导出全部备份，得到一个 .json 文件。以后拖回来就能全部恢复。

08

电脑和手机共用一份

Sync with GitHub Gist

用 GitHub 的 Gist 存一份云端副本。不用额外装东西，免费。第一次设置大约 3 分钟：

  1. 登录 GitHub，打开 Settings → Developer settings → Personal access tokens → Tokens (classic)，新建一个，只勾选 gist，复制生成的 Token。
  2. 在电脑上打开 更多 → 备份与云同步，填 Token，Gist ID 留空，点 上传到云端。Gist ID 会自动填好，把它记下来。
  3. 在手机上打开同一个页面，填同一个 Token 和刚才的 Gist ID，点 从云端拉取。
  4. 以后哪边改了，就在那边点「上传」；另一边打开时，如果云端有更新，页面顶部会提示你「拉取」。
为了不把另一台设备的改动覆盖掉，如果云端在你上次同步后被改过，上传会先被拦下，提醒你先拉取。拉取时，另一台设备删掉的书会进回收站，这台设备新加的书会保留。Token 只存在你自己的浏览器里。

11

常见问题

FAQ
打开页面发现书都不见了？

先别急着添加新书。多半是换了浏览器、用了无痕模式，或者打开的是另一个位置的文件，数据还在原来那个浏览器里。回到原来的浏览器打开，导出备份，再拖到新的地方导入。如果设置过云同步，填上 Token 和 Gist ID，点「从云端拉取」就回来了。

Word 导入后有乱码，或者少了东西？

老的 .doc 格式只能尽量读出文字。在 Word 或 WPS 里打开，另存为 .docx 再导入，效果会好很多。表格会变成「格1 | 格2」这样一行一行的文字，图片不会导入。

手机上能用吗？

能。手机浏览器打开同一个页面就行，排版会自动变成单栏。两边想用同一份书，看上面第 08 节的云同步。

Token 安全吗？

Token 只存在你这台设备的浏览器里，只用来访问 GitHub。建议只勾选 gist 权限，这样即使泄露，别人也只能动你的 Gist。不用了可以在「备份与云同步」里点「清除这台设备上的 Token」，或者去 GitHub 上把它删掉。

提示「浏览器存储空间不足」？

浏览器给每个页面的空间有限，大约 5MB。可以清空回收站，删掉不用的背景图，或者把很少用的书导出备份后删掉。

估算的 Tokens 准吗？

是粗略估算，中文大约 1 个字算 1.3 个 token，英文和符号大约 3～4 个字符算 1 个 token。不同模型会有出入，当作参考就好。
